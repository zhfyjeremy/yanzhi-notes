# 单文件模式说明

## 定位

砚知的主场景仍然是本地知识库。单文件模式用于偶尔查看、修改一个独立 Markdown 文件,不把该文件所在目录伪装成知识库,也不要求用户先创建 `.yanzhi/`。

一个应用窗口同一时间只处于两种工作区之一:

- 知识库模式:打开一个文件夹,提供目录树、搜索、双链、标签、历史、回收站等库能力。
- 单文件模式:打开一个 `.md` / `.markdown` 文件,只保留编辑、查找、大纲和导出等轻能力。

## 数据边界

- 打开文件只读取内容,不写原文件。
- 保存必须由用户触发,默认不自动保存。
- 不创建 `.yanzhi/`,不写 meta、索引、模板、快照或回收站。
- 最近打开文件保存在应用配置目录,与知识库最近记录分开。
- 图片/附件放在**文件旁与文件同名的「<文件名>.assets/」文件夹**(每篇自带,不与同目录其它笔记混用,也不碰用户已有的 `assets/`);资源文件名可读:「<原始名>-<短哈希>.<ext>」,同内容同名。没图的笔记不建文件夹。
- 粘贴、拖入或从菜单选择新图片/附件前,必须先确认允许创建该文件夹;确认只对当前会话生效。未命名缓冲区例外:资源写入应用缓存,不碰用户目录,不弹确认。
- 双链语法按 Markdown 保留,但单文件模式不解析库目标、不跳转。

## 入口

- 欢迎页入口卡下方提供「打开 Markdown 文件」轻量入口。
- 原生菜单提供「打开 Markdown 文件…」。
- 单文件模式下可从「文件 → 新建 Markdown 文件…」或左上角「单文件 ▾ → 新建 Markdown 文件…」直接新建一个「未命名」缓冲区并立即开始编辑,**不必先选保存位置**;当前文件有未保存修改时先确认。
- 最近打开文件可从欢迎页重新打开。
- 启动时不自动恢复上次的单文件,避免临时文件变成常驻工作区。
- 可把 `.md` / `.markdown` 注册到系统「打开方式」候选中;不默认抢占系统关联。
- 可将 Markdown 文件拖入窗口打开(Tauri 环境使用系统提供的原始路径)。

## 界面

- 隐藏左侧目录树和右侧知识库面板,保留中央编辑纸张。
- 文件名作为标题展示,不允许直接编辑;改名通过「另存为」完成。未命名缓冲区标题显示「未命名文档」,顶栏路径位置显示「尚未保存到磁盘」。
- 顶栏两行:「单文件 ▾」为唯一工作区入口(回欢迎页 / 最近库直开 / 浏览其它位置或打开知识库 / 新建库 / 换文件)+ 路径只读;大标题旁只留「大纲 / 保存 / 更多」。
- 状态栏显示保存状态、字数、专注模式和完整路径。
- 保留深浅色主题、排版设置、格式工具栏、查找替换和大纲能力。
- 「存入知识库」成功后提供下一步:继续编辑单文件,或保存原文件并打开目标知识库;打开后自动定位刚转入的文档。
- 知识库左栏顶部以**文件夹名**作身份(Windows 路径按 `\` 正确取名),副标题「知识库 · 父路径」;点击展开工作区菜单。批量/新建是旁侧图标,不和身份卡挤成一块。左栏底部只保留回收站等库内工具。

## 保存与冲突

- `⌘S / Ctrl+S` 保存回原路径。
- 未命名缓冲区:`⌘S / Ctrl+S` 与「保存…」会先弹出系统保存框选择存储位置,落盘后转为普通单文件;取消选位置则保留内容、仍是未保存状态。
- 关闭、打开另一个文件、切回知识库、退出时,未命名缓冲区有未保存修改同样询问;「保存」会先选位置,「不保存」直接丢弃。
- 未命名缓冲区可以直接粘贴/插入图片与附件,不必先保存:资源先写入应用缓存里一个空壳 `.md` 同名的 `.assets/`(以它为路径锚点,不碰用户目录);保存选好位置后,把正文引用到的资源复制到「<文件名>.assets/」,文件名不变,正文引用同步改写到新目录(编辑器里的旧引用按映射换算,不重载、不丢光标)。
- 「存入知识库…」仍需先保存:它按源文件名建文档并复制文件旁的资源。
- 正文里删除图片/附件**不会自动删文件**(⌘Z 撤回永远完整;Typora/Obsidian 同口径)。孤儿文件用「更多 → 清理未引用图片…」手动处理:列出「<文件名>.assets/」里未被正文引用的文件,确认后删除,删空后目录一并移除;未命名缓冲区不提供(资源在缓存)。
- 未命名缓冲区暂不写崩溃恢复草稿(草稿槽位按文件路径单槽,避免覆盖其它文件的草稿)。
- `⇧⌘S / Ctrl+Shift+S` 另存为新文件,目标重名时自动追加 `(2)`,不覆盖。换名/换目录时,正文引用到的资源复制到「<新文件名>.assets/」并同步改写引用;原文件与其资源目录不受影响。
- 关闭文件、打开另一个文件或切回知识库前,若有未保存修改需确认。
- 磁盘文件被外部修改(监听文件所在目录):
  - 本地无修改时自动重载;
  - 本地有修改时提示「保留我的修改 / 载入磁盘版本」。
- 原文件被删除或移动时保留编辑内容:编辑器顶部显示非阻塞提示条(「文件已被删除或移动,编辑内容仍保留」+「另存为…」),状态栏显示「文件已丢失」;此时 `⌘S` / 「保存」直接转「另存为」选新位置,不再静默失败。
- 只读或保存失败时保留未保存状态并明确提示。
- 写入使用同目录临时文件后原子替换,降低保存中断损坏文件的概率。
- 崩溃恢复草稿只写入应用缓存目录;重新打开同一文件时提示「恢复草稿 / 使用磁盘版本」。
- 「存入知识库…」复制当前文件与引用的本地资源,原文件不被移动或修改。

## 能力边界

保留:

- Markdown 编辑与统一解析/序列化链路
- 格式工具栏
- 查找替换
- 大纲(左侧栏默认展开;无目录树时占导航位。顶部「显示 → 大纲」与工具栏左侧图标同一状态;知识库右栏 TOC 偏好独立不串)
- 主题与排版设置
- 导出 Markdown / 离线 HTML

禁用:

- 目录树
- 全库搜索
- 标签
- 反向链接
- 历史快照
- 回收站
- 批量操作
- 文档图谱
- 知识库模板
